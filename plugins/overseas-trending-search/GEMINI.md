# Overseas Trending Search

Cross-platform trending search across X, TikTok and YouTube in one query

## Usage

This extension provides the **overseas-trending-search** skill for Gemini CLI.

- Skill definition: `skills/overseas-trending-search/SKILL.md` — read it to learn when and how to activate the skill.
- Scripts: `skills/overseas-trending-search/scripts/` — invoke them with `python3` as documented in SKILL.md.

## API Key

This skill calls the Redfox API. Set your key before use:

```bash
export REDFOX_API_KEY="rf-your-key-here"
```

Get a free key at: https://redfox.hk/settings/api-keys?source=gemini-cli
