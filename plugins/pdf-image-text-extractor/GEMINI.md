# Pdf Image Text Extractor

Extract text from PDFs and images with format preservation and table detection

## Usage

This extension provides the **pdf-image-text-extractor** skill for Gemini CLI.

- Skill definition: `skills/pdf-image-text-extractor/SKILL.md` — read it to learn when and how to activate the skill.
- Scripts: `skills/pdf-image-text-extractor/scripts/` — invoke them with `python3` as documented in SKILL.md.

## API Key

This skill calls the Redfox API. Set your key before use:

```bash
export REDFOX_API_KEY="rf-your-key-here"
```

Get a free key at: https://redfox.hk/settings/api-keys?source=gemini-cli
