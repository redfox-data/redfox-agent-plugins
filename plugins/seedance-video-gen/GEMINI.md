# Seedance Video Gen

Text-to-video generation with resolution, aspect ratio and duration control

## Usage

This extension provides the **seedance-video-gen** skill for Gemini CLI.

- Skill definition: `skills/seedance-video-gen/SKILL.md` — read it to learn when and how to activate the skill.
- Scripts: `skills/seedance-video-gen/scripts/` — invoke them with `python3` as documented in SKILL.md.

## API Key

This skill calls the Redfox API. Set your key before use:

```bash
export REDFOX_API_KEY="rf-your-key-here"
```

Get a free key at: https://redfox.hk/settings/api-keys?source=gemini-cli
