# Image Gen

Text-to-image and image-to-image generation powered by GPT-image-2

## Usage

This extension provides the **image-gen** skill for Gemini CLI.

- Skill definition: `skills/image-gen/SKILL.md` — read it to learn when and how to activate the skill.
- Scripts: `skills/image-gen/scripts/` — invoke them with `python3` as documented in SKILL.md.

## API Key

This skill calls the Redfox API. Set your key before use:

```bash
export REDFOX_API_KEY="rf-your-key-here"
```

Get a free key at: https://redfox.hk/settings/api-keys?source=gemini-cli
