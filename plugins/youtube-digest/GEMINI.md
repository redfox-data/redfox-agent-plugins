# Youtube Digest

Extract YouTube video transcripts (subtitles/voice-over) as clean text or Excel

## Usage

This extension provides the **youtube-digest** skill for Gemini CLI.

- Skill definition: `skills/youtube-digest/SKILL.md` — read it to learn when and how to activate the skill.
- Scripts: `skills/youtube-digest/scripts/` — invoke them with `python3` as documented in SKILL.md.

## API Key

This skill calls the Redfox API. Set your key before use:

```bash
export REDFOX_API_KEY="rf-your-key-here"
```

Get a free key at: https://redfox.hk/settings/api-keys?source=gemini-cli
