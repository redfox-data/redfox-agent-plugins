# Twitter Video Downloader

Watermark-free X/Twitter video downloader with direct MP4 links

## Usage

This extension provides the **twitter-video-downloader** skill for Gemini CLI.

- Skill definition: `skills/twitter-video-downloader/SKILL.md` — read it to learn when and how to activate the skill.
- Scripts: `skills/twitter-video-downloader/scripts/` — invoke them with `python3` as documented in SKILL.md.

## API Key

This skill calls the Redfox API. Set your key before use:

```bash
export REDFOX_API_KEY="rf-your-key-here"
```

Get a free key at: https://redfox.hk/settings/api-keys?source=gemini-cli
